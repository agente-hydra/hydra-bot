# 🚀 AGY Workspace — Google Antigravity Hardened

Pasta dedicada e configurada exclusivamente para o **AGY CLI** com arquitetura anti-alucinação, persistência de memória modular (Obsidian) e controle estrito de contexto.

---

## ⚡ Como Iniciar

1. **Dois cliques:** Execute o arquivo `iniciar-agy.bat`.
   *OU*
2. **Via Terminal:** Abra o PowerShell ou CMD dentro desta pasta e digite:
   ```bash
   agy
   ```

---

## 🧠 Memória Persistente (Obsidian)

Toda a memória da IA é armazenada em formato Markdown em:
📁 `.agent/memory/`
- `auth.md`: Sessões, tokens e segurança.
- `domain.md`: Regras de negócio e especificações do projeto.
- `infra.md`: Configurações de ambiente, deploy e variáveis.
- `supabase.md`: Banco de dados, queries e regras de acesso.
- `ui.md`: Componentes, layouts e estilos visuais.
- `sessions.md`: Histórico e continuidade entre sessões.

> **Dica Obsidian:** Se quiser visualizar suas notas em formato de grafo visual, basta abrir o Obsidian e selecionar **"Open folder as vault"** apontando para a pasta `.agent/memory/`.
